# fdtdx_validation — independent FDTDX validation of the frozen activation finalists

Order of operations (enforced): TORCWA campaign closed (`../REPORT.md`) -> finalists frozen here
(`register_finalists.py` -> `manifest.json`, `<tag>/geometry/`) -> FDTDX reference + production runs
(`fx_run.py`, wrapper around the validated `../../fdtdx_four_finalists/fx_sim.py`) -> raw complex phasors
(`<tag>/raw_fields/prod/phasors.npz`, gitignored, regenerated by the run; `run_meta.json` committed) ->
plots and cross-checks from the raw data only (`fx_fields_plots.py`) -> `VALIDATION_SUMMARY.md`.
Nothing here feeds back into the design stage; no geometry is modified.

Layout per candidate:

    <tag>/geometry/rho_hard_binary.npy, geometry_<tag>.png      frozen uint8 mask (SHA256 in manifest.json), drawn from the binary
    <tag>/raw_fields/prod/phasors.npz + run_meta.json           RAW detector phasors (E and H volume, xz/yz planes, R/T flux planes, probes)
    <tag>/raw_fields/fields_normalized.npz                      complex E/E_inc (and H/E_inc) with true x/y/z centres and edges, layer indices
    <tag>/spectra/spectra_<tag>.{csv,npz,png}, checks_<tag>.json FDTDX R/T/A vs TORCWA cold state; artefact, convergence and decay checks
    <tag>/profiles/zprofile_<tag>.{png,npz}, zprofile_<tag>_<lam>nm.csv   <|E|^2>, <|Ez|^2>, <|Dz|^2> vs z through air / a-Si:H / ITO / glass
    <tag>/xy_slices/Ez2_xy_slices_<tag>_<lam>nm_{lin,log}.png + .npz     many-z |Ez|^2 maps on one colour scale
    <tag>/xz_yz/Ez2_{xz,yz}_<tag>_<lam>nm.png                   full-height cuts on the true non-uniform z mesh (pcolormesh)
    <tag>/metadata/plot_manifest.json                           provenance of every figure
    reference/<tag>_prod/                                        empty-cell reference run of the identical mesh
    geometry_all_candidates.png, manifest.json, materials_fit_check.json, METHOD.md, VALIDATION_SUMMARY.md

Reproduce (after the campaign): `./run_validation.sh <tag> [...]` with `/opt/venv-fdtdx` (fdtdx main-branch
snapshot 98aef1c, jax 0.10.2, CPU).  Materials: the four-finalists ADE fits of the supplied files
(`../../fdtdx_four_finalists/materials/material_models.json`; errors over 1252-1400 nm: eps' <= 0.0014,
eps'' <= 0.0042, fitted ENZ crossing 1302.13 nm vs 1302.28 nm supplied, `materials_fit_check.json`).
